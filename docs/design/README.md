# LocalHub design foundation

These concept boards are reference-only:

- `customer-discovery-concept.png`
- `merchant-dashboard-concept.png`
- `admin-control-center-concept.png`

They may contain legacy “Lafia Hub” wording. The product-facing master brand is **LocalHub**; **Lafia, Nasarawa State** is the first launch-market configuration. The images are not rendered application UI, and their names, metrics, rows, prices, and statuses are not approved facts.

## Visual direction

LocalHub should feel calm, trustworthy, locally grounded, spacious, and easy to use. Use code-native components, a dependable self-hosted or system sans-serif stack, a 4px spacing base, 16–20px radii, light borders, restrained shadows, 44px minimum touch targets, 150–200ms transitions, and reduced-motion support.

| Token        | Value     | Use                                      |
| ------------ | --------- | ---------------------------------------- |
| Canvas       | `#f8fafc` | Secondary bands and dashboard canvas     |
| Surface      | `#ffffff` | Primary backgrounds and controls         |
| Ink          | `#0f172a` | Headlines and high-emphasis text         |
| Body         | `#334155` | Body copy and labels                     |
| Muted        | `#64748b` | Supporting text                          |
| Primary      | `#2557e8` | Primary actions and selected navigation  |
| Intelligence | `#6d45e8` | Restrained Ask/AI accents                |
| Coral        | `#ef6359` | Warnings and warmth, sparingly           |
| Border       | `#e2e8f0` | Boundaries                               |
| Focus        | `#1d4ed8` | Keyboard focus                           |
| Success      | `#15803d` | Positive statuses with text/icon support |
| Warning      | `#b45309` | Pending statuses with text/icon support  |
| Danger       | `#b91c1c` | Destructive actions with confirmation    |

Customer surfaces use a quiet header, useful local discovery, a category rail on small screens, and mobile bottom navigation. Merchant surfaces use a desktop left rail and mobile bottom navigation. Admin is desktop-first and operational. Ask LocalHub is the dominant customer action. Status must never be communicated by colour alone.

Do not use glassmorphism, neon/glow, excessive gradients, generic AI-robot imagery, nested card grids, or decorative filler. Phase 1 media is code-native, abstract, and explicitly demo data where applicable.

## Copy and data guardrails

The first customer viewport may use only approved LocalHub/Lafia discovery copy from the specification. Do not add unapproved claims, popularity, scarcity, ratings, stock, reviews, or large platform metrics. Fixtures must be fictional, marked `demo`, and visibly identified as demonstration data.

The provisional network mark is replaceable because final brand artwork was not supplied. Non-Lafia concept rows and the partially visible extra customer section are not Phase 1 requirements.
